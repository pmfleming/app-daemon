Ranked findings and implementation
1. software::compose: production cognitive maximum 15, cyclomatic 12, function
   effort 244120. Temporary matched-ID strings/vector, fallible relookup and a
   full installation clone for every match. Package now owns installation
   derivation; matched records are borrowed directly and the first takes ownership.
   For n matches: zero temporary ID clones, n-1 installation clones instead of n.
   Global staleness is merged into optional release evidence without nested guards.
2. software persistence: cloned every record merely to clear metadata entries;
   refresh decoded the catalog twice. Metadata now copies scalar fields and only
   the optional error string; refresh returns either the existing stored snapshot
   or the just-committed new value. SQL-owned string parameters remain explicit
   clones: replacing them with &str would only hide the same Turso allocation.
3. Repeated database-count and private-bus acceptance setup obscured assertions.
   Shared test helpers retain all distinct checks and strengthen acceptance to
   require both ok and accepted lifecycle status. Combined restart/rollback/retry
   scenarios reuse one fixture. No ignored tests or safety assertions removed.
4. Added worker-ingestion tests for valid output, exact 2 MiB, one byte over,
   malformed JSON, schema rejection, nonzero exit and relative executable paths;
   catalog matrices add shared identities/deduplication, observation-order stable
   revisions, release precedence/fallback/default staleness and retained diagnostics.
5. Remaining hotspots: history query_window (cyclomatic 23, effort 165200),
   software store open (31, 126729), history finish (cognitive 14), durable operation
   admission (21, 124416); the large opt-in workspace journey remains the test
   effort/cognitive maximum. Security-sensitive private_file duplication remains
   in history/software stores. No compiler/search proof justified speculative
   dead-code deletion; no public API removed or lint/unsafe escape added.
